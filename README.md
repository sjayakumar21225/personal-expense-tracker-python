# personal-expense-tracker-python
A beginner-friendly Python CLI application to record, search, and analyze personal expenses.
A simple command-line Expense Tracker built with Python to help users manage and analyze their daily expenses.


🚀 Features

Add and view daily expenses
Monthly summary of spending
Search expenses by keyword
Automatic spending insights
Lightweight & file-free version — easy to test on OneCompiler


🧠 Concepts Used

Lists & Dictionaries
Loops & Conditionals
Functions & Modular Code
Basic Data Analysis Logic


💻 How to Run

1. Copy the code from main.py
2. Paste it into OneCompiler Python
3. Click Run
4. Test options:

1️⃣ Add Expense
2️⃣ View All Expenses
3️⃣ Monthly Summary
4️⃣ Search Expenses
5️⃣ Insights
6️⃣ Exit
